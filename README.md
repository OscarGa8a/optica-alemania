# Óptica Alemania — Villavicencio

Sitio web institucional y concepto digital para Óptica Alemania en Villavicencio, Meta, Colombia.

## 🚀 Tecnologías

- **Framework:** [Astro](https://astro.build/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Tipografía:** [Instrument Serif](https://fontsource.org/fonts/instrument-serif) (editorial) e [Inter](https://fontsource.org/fonts/inter) (interfaz)
- **Iconografía:** [Lucide Astro](https://lucide.dev/)
- **Pruebas Visuales:** [Playwright](https://playwright.dev/)

## 📁 Documentación e Identidad

La información de marca, diseño y contenidos se encuentra en el directorio [`docs/`](./docs):
- [`docs/design_system.md`](./docs/design_system.md): Tokens cromáticos, tipografía y retícula.
- [`docs/blueprint.md`](./docs/blueprint.md): Arquitectura de contenidos y flujos de usuario.
